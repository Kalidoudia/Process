## 3. Édition de la page avec Elementor

### Introduction à Elementor

- **Accéder à l'éditeur Elementor** :  
  Cliquez sur **Modifier avec Elementor** pour accéder à l'interface d'Elementor, qui vous permet de personnaliser facilement la mise en page de vos pages.

- **Interface utilisateur d'Elementor** :  
  L'interface d'Elementor est composée de trois zones principales : la barre latérale avec les widgets, la zone de contenu central pour la page, et les options d'édition en haut de l'écran.

### Structure de la page

- **Création de sections et de colonnes** :  
  Elementor vous permet de diviser une page en sections et d'ajouter des colonnes à ces sections. Cela vous aide à organiser les éléments de manière claire et responsive.

- **Ajouter des widgets** :  
  Vous pouvez ajouter différents types de widgets (texte, images, vidéos, formulaires, boutons, etc.) pour enrichir le contenu de la page.

- **Organisation des éléments** :  
  Organisez les widgets en les faisant glisser et en utilisant les options d'alignement et de style.

---

## 4. Création de blocs Elementor

### Création de blocs Elementor globaux

- **Qu'est-ce qu'un bloc global ?**  
  Un bloc global est un élément réutilisable dans plusieurs pages. Vous pouvez créer des sections globales et les insérer dans différentes pages.

- **Sauvegarder et réutiliser des blocs** :  
  Une fois un bloc créé, vous pouvez le sauvegarder dans la bibliothèque Elementor pour le réutiliser plus tard.

## 5. Organisation des éléments dans Elementor

### Disposition et alignement des éléments

- **Organiser les colonnes, sections et widgets** :  
  Utilisez les outils d'alignement d'Elementor pour disposer vos éléments de manière fluide, tout en assurant une bonne responsivité.

### Utilisation de CSS et HTML

- **Ajouter des styles CSS personnalisés** :  
  Vous pouvez ajouter des règles CSS directement dans les widgets ou dans la section **Paramètres** → **CSS personnalisé** pour personnaliser l'apparence de vos éléments.

- **Ajouter du code HTML personnalisé** :  
  Utilisez le widget HTML pour insérer du code HTML, du JavaScript ou d'autres contenus personnalisés dans la page.

---

## 6. Utilisation des éléments Elementor no-code

- **Ajouter des éléments sans code** :  
  Elementor permet de personnaliser les pages sans coder. Utilisez les widgets comme **Image**, **Texte**, **Galerie**, **Formulaires**, etc., pour ajouter des éléments sans avoir besoin de programmer.

---

## 7. Création de modèles réutilisables

### Créer un modèle de page

- **Sauvegarder des sections comme modèles** :  
  Si vous avez créé une page que vous souhaitez réutiliser, vous pouvez la sauvegarder en tant que modèle. Allez dans la section **Modèles** dans Elementor et cliquez sur **Enregistrer comme modèle**.

- **Importer et exporter des modèles** :  
  Elementor permet d’importer et d’exporter des modèles, ce qui est utile pour partager des mises en page avec d'autres utilisateurs.

---

## 8. Gestion des URLs et du nom de la page

### Définir l'URL d'une page

- **Modifier l'URL de la page** :  
  Vous pouvez personnaliser l'URL de votre page dans la section **Permaliens** de l'éditeur de page pour mieux la structurer pour le SEO.

### Gestion du nom de la page

- **Modifier le nom de la page dans la liste des pages** :  
  Assurez-vous que le nom de la page est clair et précis pour qu'il soit facile à retrouver dans la liste des pages WordPress.

---

## 9. Mode révision et gestion des versions de page

### Passer une page en mode révision

- **Mettre une page en mode brouillon** :  
  Si vous souhaitez continuer à travailler sur une page sans la publier, vous pouvez la mettre en mode **Brouillon**.

- **Utiliser les révisions WordPress** :  
  WordPress enregistre automatiquement les révisions de la page. Vous pouvez consulter et revenir à une version précédente via la fonction **Révisions** dans l'éditeur de page.
