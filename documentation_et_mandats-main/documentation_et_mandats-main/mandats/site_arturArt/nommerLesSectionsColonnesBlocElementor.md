## Détails techniques : 

Le nom doit être explicite et ce qui est dans le bloc ou les blocs elementors contenus dans la colonne, section. 

- Donc, si une section ne contient qu'un titre, alors nommer la section et la colonne titre. 
- Si la section contient un titre et un bouton qui rediriger vers une autre page de sousBlog, alors titreBoutonVersBlog.  

Le but est qu'on sait le plus tôt possible à quoi sert ce qui est dans la section, la colonne sans avoir à naviguer dans tous les sous-onglets.
